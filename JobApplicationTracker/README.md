# Job Application Tracker

## Project Description

A C# Console Application that manages companies, recruiters, job vacancies, candidates, and job applications using in-memory data storage.

## Technologies Used

- C#
- .NET
- Object-Oriented Programming
- Generics and Collections
- List, Dictionary, HashSet, and Stack
